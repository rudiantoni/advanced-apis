# v0.0.11a (Sub-Phase 11a): Global MVC error handling (known failures)

Part of the **error handling evolution phase** (read the **phase 11 index** first).

**Incremental** on all prior guides through the **manual input validation phase**.

Goals:

1. Centralize known MVC error mapping in one `@RestControllerAdvice`.
2. Handle `MultiErrorException` globally so controllers stay focused on success flow.
3. Handle malformed request bodies (`HttpMessageNotReadableException`) globally with the same `400` message already used by the API.
4. Remove the abstract request-body base controller now that exception mapping is global.
5. Remove controller-level `try/catch` for `MultiErrorException` and type controller responses with success DTOs.

## API change

The public error body shape remains unchanged:

```json
{ "errors": ["message"] }
```

Observed behavior after this sub-phase:

- Validation and domain errors raised as `MultiErrorException` are mapped by the global advice.
- Malformed JSON in `@RequestBody` endpoints returns `400` with:
  `{"errors":["Request body is invalid or malformed JSON"]}`.
- Login failure still returns `401` with `{"errors":["Unauthorized"]}` through `MultiErrorException`.

## Verify

1. `POST /api/auth/login` with wrong credentials -> `401` with `{"errors":["Unauthorized"]}`.
2. `POST /api/auth/login` with malformed JSON -> `400` with malformed-body message.
3. `POST /api/users` with invalid payload (missing required fields) -> `400` with the same validation `errors` list pattern.
4. `GET /api/products/{id}` with missing id -> `404` with `{"errors":["Product not found with id: ..."]}`.
5. Protected endpoint without valid JWT still returns `401` from the filter using the same error shape.

## Files

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/exception/GlobalExceptionHandler.java`

Global REST advice that centralizes known MVC error mapping using the existing API contract.

```java
package com.myapps.bavariamunich.exception;

import com.myapps.bavariamunich.dto.ErrorResponseDto;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MultiErrorException.class)
    public ResponseEntity<ErrorResponseDto> handleMultiError(MultiErrorException ex) {
        return new ResponseEntity<>(new ErrorResponseDto(ex.getErrors()), ex.getStatus());
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public ResponseEntity<ErrorResponseDto> handleHttpMesageNotReadable(HttpMessageNotReadableException ex) {
        ErrorResponseDto result = ErrorResponseDto.of("Request body is invalid or malformed JSON");
        return new ResponseEntity<>(result, HttpStatus.BAD_REQUEST);
    }
}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/controller/AuthController.java`

Controller no longer extends the old request-body base class. Login failure now throws `MultiErrorException` and lets the global advice produce the error response.

```java
package com.myapps.bavariamunich.controller;

import com.myapps.bavariamunich.config.AppConsts;
import com.myapps.bavariamunich.dto.AuthLoginRequestDto;
import com.myapps.bavariamunich.dto.AuthLoginResponseDto;
import com.myapps.bavariamunich.exception.MultiErrorException;
import com.myapps.bavariamunich.service.AuthService;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/auth")
public class AuthController {

    // ...

    @PostMapping("/login")
    public ResponseEntity<AuthLoginResponseDto> login(@RequestBody AuthLoginRequestDto body) {
        String token = authService.login(body);
        if (token == null) {
            throw new MultiErrorException(HttpStatus.UNAUTHORIZED, AppConsts.UNAUTHORIZED);
        }
        AuthLoginResponseDto result = new AuthLoginResponseDto(token);
        return new ResponseEntity<>(result, HttpStatus.OK);
    }
}
```
