# v0.0.1b (Sub-Phase 1b): Container image and local Compose

Part of the **platform integrations phase** (read the **platform integrations phase index** first).

**Prerequisites:**

1. Complete the **platform configuration sub-phase** (profiles `local` / `cloud`, `.env.example` → `.env.local`).
2. Shared Postgres is optional at this step for the scaffold-only API, but when the API container must reach Postgres on the monorepo network:
   - Start the stack under [`docker/dev`](../../../docker/dev/) first so the database is up.
   - The Compose network must be available to other projects as an **external** network named `dev_default`.
   - Compose overrides `DATABASE_HOST` to the Postgres **service name** (`postgres_18` in `docker/dev`; see `docker-compose.yml` below); keep `localhost` in `.env.local` for IDE / host use.

This sub-phase adds a **multi-stage Dockerfile**, a shell **entrypoint**, and a module-level **`docker-compose.yml`** so the API runs in a container with the **`cloud`** profile and environment from **`.env.local`**.

Goals:

1. Build a production-style image (Corretto 8 Alpine, non-root user, fat JAR).
2. Start the JVM through `docker-entrypoint.sh` (profile `cloud` via `-Dspring.profiles.active=cloud`).
3. Run the API container attached to the shared Docker network `dev_default`.
4. Reuse `.env.local` for Compose, with container-specific overrides where needed.

## Run

Do this **after** the file changes in **Files** below. Ensure the `dev_default` network already exists if Compose requires the external network. Create **`.env.local`** from `.env.example` if needed. All commands assume the current directory is `api-java-bavaria-munich/`.

Use `--env-file .env.local` so Compose interpolates `${SERVER_PORT}` (and similar) from the same file the container receives via `env_file`.

Smoke check after the container is up: `GET http://localhost:8080/api/open/check` (use `SERVER_PORT` from `.env.local` if it differs).

```bash
curl http://localhost:8080/api/open/check
```

### Docker Compose - build (or rebuild) and start

```bash
docker compose --env-file .env.local up -d --build
```

### Docker Compose - start (image already built)

```bash
docker compose --env-file .env.local up -d
```

### Docker Compose - stop

```bash
docker compose --env-file .env.local down
```

## Files

### `api-java-bavaria-munich/.env.local`

**Create locally** (gitignored). Copy from `.env.example` (or create it from scratch) and adjust values for your machine. Compose loads this file via `env_file` and `--env-file`.

```env
SERVER_PORT=8080
CONTEXT_PATH=/api
```

Change `SERVER_PORT` if you want a different host-mapped port; keep `CONTEXT_PATH` aligned with the API prefix (`/api`).

### `api-java-bavaria-munich/docker-entrypoint.sh`

Shell entrypoint used by the image. Starts the fat JAR with the `cloud` profile.

```sh
#!/bin/sh
set -e

exec java -Dspring.profiles.active=cloud -jar /app/app.jar
```

### `api-java-bavaria-munich/Dockerfile`

Multi-stage build: JDK stage runs `bootJar`, JRE stage runs the app as a non-root user via the entrypoint.

```dockerfile
# ---- Build ----
FROM amazoncorretto:8-alpine3.21-jdk AS build

WORKDIR /app

COPY gradlew settings.gradle build.gradle ./
COPY gradle ./gradle
RUN chmod +x gradlew

COPY src ./src

RUN ./gradlew bootJar --no-daemon -x test \
    && cp build/libs/api-java-bavaria-munich-*.jar app.jar

# ---- Run ----
FROM amazoncorretto:8-alpine3.21-jre AS run

WORKDIR /app

RUN addgroup -g 10001 appgroup \
    && adduser -D -u 10001 -G appgroup appuser

COPY --from=build --chown=appuser:appgroup /app/app.jar /app/app.jar
COPY --chown=appuser:appgroup docker-entrypoint.sh /app/docker-entrypoint.sh

RUN chmod +x /app/docker-entrypoint.sh

USER appuser

ARG SERVER_PORT=8080
EXPOSE ${SERVER_PORT}

ENTRYPOINT ["/app/docker-entrypoint.sh"]
```

### `api-java-bavaria-munich/docker-compose.yml`

Builds the image, loads env from **`.env.local`**, overrides `DATABASE_HOST` for the shared network, maps the host port, and attaches to `dev_default`.

```yml
services:
  api-java-bavaria-munich:
    container_name: api-java-bavaria-munich
    build:
      context: .
      dockerfile: Dockerfile
      args:
        SERVER_PORT: ${SERVER_PORT:-8080}
    image: api-java-bavaria-munich
    restart: unless-stopped
    env_file:
      - .env.local
    environment:
      DATABASE_HOST: postgres_18
    ports:
      - "${SERVER_PORT:-8080}:${SERVER_PORT:-8080}"
    networks:
      - shared

networks:
  shared:
    external: true
    name: dev_default
```
