# v0.0.7 (Phase 7): Route protection

**Incremental** on all prior guides in filename order through the **shared-utilities phase**.

**Scaffold replacement:** This phase replaces the remaining **scaffold-phase** placeholders in `AppConsts` (`MY_CONST`) and `AppProperties` (`myProperty`). `AppConfig` was already replaced in the **shared-utilities phase**; here you **extend** it with `initializeProperties()` for `public-routes` only. Replace each holder with the **full** snippets below - do not merge scaffold members alongside the new ones.

Goals:

1. Load public-route rules from configuration (`app.security.public-routes` in `application-local.yml` or environment variables for the `cloud` profile).
2. Compile path regex and optional HTTP-method rules into matchers used at runtime.
3. Register a servlet filter and Spring Security so requests that are **not** public receive `401 Unauthorized` with body `{"message":"Unauthorized"}` before controllers run.
4. Extend `OpenApiConfig` from the **API documentation sub-phase** so Swagger UI lock icons match `public-routes`, regardless of having authentication or not.

## API change

From this phase on:

- A request is **public** when its servlet path and HTTP method match any entry in `app.security.public-routes` - for example `GET /api/open/check` and Swagger UI paths work without credentials.
  - Optional `methods` on an entry limits publicity to those verbs only on that path.
- All other requests (including `GET /api/closed/check` and product routes) return `401 Unauthorized` with body `{"message":"Unauthorized"}`.
- There is no way to authenticate protected routes until you implement an **authentication sub-phase**.
- Enforcement is in `RouteProtectionFilter`, not inside controllers.

## Verify

1. `GET /api/open/check` → `200 OK`.
2. `GET /api/closed/check` → `401` with `{"message":"Unauthorized"}`.
3. Swagger UI loads at `/api/swagger-ui/index.html`; `GET /open/check` shows **without** a lock icon; protected operations show a lock

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/auth/PublicRouteRule.java`

Compiled matcher: path regex plus optional HTTP methods. Empty or missing `methods` means all methods on a matching path are public.

```java
package com.myapps.bavariamunich.auth;

import org.springframework.http.HttpMethod;

import java.util.Collections;
import java.util.EnumSet;
import java.util.List;
import java.util.Set;
import java.util.regex.Pattern;
import java.util.stream.Collectors;

public class PublicRouteRule {

    private final Pattern pattern;
    private final Set<HttpMethod> methods;

    public PublicRouteRule(String routeRegex, List<String> methodNames) {
        if (routeRegex == null || routeRegex.trim().isEmpty()) {
            throw new IllegalArgumentException("Public route regex must not be blank");
        }
        this.pattern = Pattern.compile(routeRegex);
        this.methods = normalizeMethods(methodNames);
    }

    public boolean matches(String servletPath, String httpMethod) {
        if (servletPath == null || !pattern.matcher(servletPath).matches()) {
            return false;
        }
        if (methods.isEmpty()) {
            return true;
        }
        return methods.contains(HttpMethod.valueOf(httpMethod));
    }

    private static Set<HttpMethod> normalizeMethods(List<String> methodNames) {
        if (methodNames == null || methodNames.isEmpty()) {
            return Collections.emptySet();
        }
        return methodNames.stream()
                .map(String::trim)
                .map(String::toUpperCase)
                .map(HttpMethod::valueOf)
                .collect(Collectors.toCollection(() -> EnumSet.noneOf(HttpMethod.class)));
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/AppConfig.java`

Extends `AppConfig` from the **shared-utilities phase**: `initializeJsonUtil()` is unchanged; `init()` also calls `initializeProperties()`.

Property parsing uses `objectMapper.readValue(...)` directly - not `JsonUtil`.

Add these imports to the existing `AppConfig` (keep imports already there):

```java
import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.core.type.TypeReference;
import com.myapps.bavariamunich.definition.PublicRouteDefinition;

import java.util.List;
import java.util.Objects;
```

Member-level changes:

```java
@Configuration
public class AppConfig {

    // ... constructor, fields, initializeJsonUtil()

    private void init() {
        logger.info("AppConfig initialization started");
        initializeJsonUtil();
        initializeProperties();
        logger.info("AppConfig initialization finished");
    }

    // ...

    private void initializeProperties() {
        try {
            AppProperties.setSecurityPublicRoutes(getSecurityPublicRoutes());
        } catch (Exception e) {
            logger.error("Unable to initialize properties.", e);
            throw new IllegalStateException("Unable to initialize properties.", e);
        }
    }

    private List<PublicRouteDefinition> getSecurityPublicRoutes() throws JsonProcessingException {
        String property = "app.security.public-routes";
        String propertyValue = env.getRequiredProperty(property);

        List<PublicRouteDefinition> securityPublicRoutes = Objects.requireNonNull(
                objectMapper.readValue(propertyValue, new TypeReference<List<PublicRouteDefinition>>() {
                }),
                "Unable to parse " + property
        );

        securityPublicRoutes.stream()
                .filter(it -> it.getRoute() == null || it.getRoute().trim().isEmpty())
                .findFirst()
                .ifPresent(ignored -> {
                    throw new IllegalStateException(String.format("Each public route must have a non-empty route." +
                            "\nProperty %s raw value: %s" +
                            "\nParsed routes=%s", property, propertyValue, securityPublicRoutes));
                });

        return securityPublicRoutes;
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/AppBeansConfig.java`

Exposes compiled public-route rules as a `List<PublicRouteRule>` bean for the filter.

```java
package com.myapps.bavariamunich.config;

import com.myapps.bavariamunich.auth.PublicRouteRule;
import com.myapps.bavariamunich.definition.PublicRouteDefinition;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.context.annotation.DependsOn;

import java.util.Collections;
import java.util.List;
import java.util.stream.Collectors;

@Configuration
@DependsOn("appConfig")
public class AppBeansConfig {

    @Bean
    public List<PublicRouteRule> publicRouteRules() {
        List<PublicRouteDefinition> definitions = AppProperties.getSecurityPublicRoutes();
        if (definitions == null) {
            return Collections.emptyList();
        }
        return definitions.stream()
                .map(it -> new PublicRouteRule(it.getRoute(), it.getMethods()))
                .collect(Collectors.toList());
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/auth/RouteProtectionFilter.java`

`OncePerRequestFilter` that allows public requests and returns `401` for all others. Uses the `List<PublicRouteRule> publicRouteRules` bean from `AppBeansConfig`.


```java
package com.myapps.bavariamunich.auth;

import com.myapps.bavariamunich.config.AppConsts;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import javax.servlet.FilterChain;
import javax.servlet.ServletException;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.List;

@Component
public class RouteProtectionFilter extends OncePerRequestFilter {

    private final List<PublicRouteRule> publicRouteRules;

    public RouteProtectionFilter(
            @Qualifier("publicRouteRules") List<PublicRouteRule> publicRouteRules
    ) {
        this.publicRouteRules = publicRouteRules;
    }

    @Override
    protected void doFilterInternal(
            HttpServletRequest request, HttpServletResponse response, FilterChain filterChain
    ) throws ServletException, IOException {

        if (isPublicRequest(request)) {
            filterChain.doFilter(request, response);
            return;
        }

        writeUnauthorized(response);
    }

    private boolean isPublicRequest(HttpServletRequest request) {
        String servletPath = request.getServletPath();
        String method = request.getMethod();
        return publicRouteRules.stream()
                .anyMatch(it -> it.matches(servletPath, method));
    }

    private void writeUnauthorized(HttpServletResponse response) throws IOException {
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        response.getWriter().write(AppConsts.DEFAULT_UNAUTHORIZED_RESPONSE_JSON_STR);
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/SecurityConfig.java`

Stateless session, CSRF disabled, all requests permitted at the authorization layer (the custom filter enforces route protection), filter registered before `UsernamePasswordAuthenticationFilter` (anchor for filter order only).

```java
package com.myapps.bavariamunich.config;

import com.myapps.bavariamunich.auth.RouteProtectionFilter;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    private final RouteProtectionFilter routeProtectionFilter;

    public SecurityConfig(RouteProtectionFilter routeProtectionFilter) {
        this.routeProtectionFilter = routeProtectionFilter;
    }

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .sessionManagement()
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
                .and()
                .csrf()
                .disable()
                .authorizeRequests()
                .anyRequest()
                .permitAll()
                .and()
                .addFilterBefore(routeProtectionFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/OpenApiConfig.java`

Extends the class from the **API documentation sub-phase**. Adds a customizer so operations listed in `public-routes` show **without** a lock icon. Protected operations are marked as requiring authentication (scheme details are added in an **authentication sub-phase**).

Add these imports:

```java
import com.myapps.bavariamunich.auth.PublicRouteRule;
import io.swagger.v3.oas.models.security.SecurityRequirement;
import org.springdoc.core.customizers.OpenApiCustomiser;
import org.springframework.beans.factory.annotation.Qualifier;

import java.util.Collections;
import java.util.List;
```

Add the constant and bean:

```java
@Configuration
public class OpenApiConfig {

    private static final String PENDING_AUTH = "pendingAuth";

    // ... existing openApi() bean from the API documentation sub-phase

    @Bean
    public OpenApiCustomiser publicRoutesOpenApiCustomiser(
            @Qualifier("publicRouteRules") List<PublicRouteRule> publicRouteRules
    ) {
        return openApi -> {
            if (openApi.getPaths() == null) {
                return;
            }
            openApi.getPaths().forEach((path, pathItem) -> {
                pathItem.readOperationsMap().forEach((method, operation) -> {
                    boolean isPublic = publicRouteRules.stream()
                            .anyMatch(rule -> rule.matches(path, method.name()));
                    if (isPublic) {
                        operation.setSecurity(Collections.emptyList());
                    } else {
                        operation.setSecurity(Collections.singletonList(
                                new SecurityRequirement().addList(PENDING_AUTH)));
                    }
                });
            });
        };
    }

}
```
