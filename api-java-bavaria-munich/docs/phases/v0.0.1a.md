# v0.0.1a (Sub-Phase 1a): Externalized configuration (profiles + env)

Part of the **platform integrations phase** (read the **platform integrations phase index** first).

**Prerequisites:** complete the **scaffold phase** (executable project with check endpoints and `context-path: /api`).

This sub-phase replaces the single committed `application.yml` from the scaffold with **Spring profiles** and environment-backed configuration for the keys that already exist.

Goals:

1. Split configuration into a **`local`** profile (fixed values, gitignored) and a **`cloud`** profile (placeholders resolved from environment variables).
2. Provide [`.env.example`](../../.env.example) as a template; copy it to **`.env.local`** (gitignored) for cloud-style runs (IDE and shell).
3. Document how to activate each profile from the IDE, Gradle, and the executable JAR.

## Run

Do this **after** the file changes in **Files** below. Create `application-local.yml` and copy `.env.example` to `.env.local` first. All commands assume the current directory is `api-java-bavaria-munich/`.

Use the fat JAR from `bootJar`, not `*-plain.jar`.

Smoke check after startup: `GET http://localhost:8080/api/open/check` (use `SERVER_PORT` when on `cloud`).

```bash
curl http://localhost:8080/api/open/check
```

Confirm that `application-local.yml` and `.env.local` are **not** tracked by git.

### IntelliJ IDEA

For Gradle vs IntelliJ run settings and the harmless `BUILD FAILED` that can appear on Stop, see the module [README.md](../../README.md) (IntelliJ IDEA section).

1. Open this module so Gradle can sync.
2. Run → Edit Configurations… → use (or create) an **Application** (or **Spring Boot**) configuration.
3. **Main class:** `com.myapps.bavariamunich.ApiJavaBavariaMunichApplication`
4. **Working directory:** the module root (`…/api-java-bavaria-munich`)
5. Leave **Active profiles** empty.
6. **VM options** - choose one:
   - Local: `-Dspring.profiles.active=local`
   - Cloud: `-Dspring.profiles.active=cloud`, and load environment from **`.env.local`** (EnvFile plugin or equivalent)
7. Apply / OK, then Run.

### Gradle `bootRun`

**Local profile**

- **Windows CMD:**
  ```bat
  .\gradlew.bat bootRun --args=--spring.profiles.active=local
  ```
- **Windows PowerShell:**
  ```powershell
  .\gradlew.bat bootRun --args=--spring.profiles.active=local
  ```
- **Windows Git Bash:**
  ```bash
  ./gradlew bootRun --args='--spring.profiles.active=local'
  ```
- **Linux / macOS:**
  ```bash
  ./gradlew bootRun --args='--spring.profiles.active=local'
  ```

**Cloud profile** — set each required key from `.env.local` in the session first (only 2 environment variables are shown below as examples), then run application:

- **Windows CMD** (double inner `"` inside `set "…"` so quotes stay in the JSON value):
  ```bat
  set "JWT_SECRET=your_jet_secret_here"
  set "PUBLIC_ROUTES=[{""route"":""^/open(/.*)?$""}]"
  .\gradlew.bat bootRun --args=--spring.profiles.active=cloud
  ```
- **Windows PowerShell:**
  ```powershell
  $env:JWT_SECRET = 'your_jet_secret_here'
  $env:PUBLIC_ROUTES = '[{"route":"^/open(/.*)?$"}]'
  .\gradlew.bat bootRun --args=--spring.profiles.active=cloud
  ```
- **Windows Git Bash:**
  ```bash
  export JWT_SECRET='your_jet_secret_here'
  export PUBLIC_ROUTES='[{"route":"^/open(/.*)?$"}]'
  ./gradlew bootRun --args='--spring.profiles.active=cloud'
  ```
- **Linux / macOS:**
  ```bash
  export JWT_SECRET='your_jet_secret_here'
  export PUBLIC_ROUTES='[{"route":"^/open(/.*)?$"}]'
  ./gradlew bootRun --args='--spring.profiles.active=cloud'
  ```

## Files

### Remove `application.yml`

Delete the scaffold file:

`api-java-bavaria-munich/src/main/resources/application.yml`

### `api-java-bavaria-munich/src/main/resources/application-cloud.yml`

Committed profile for cloud-style runs.

```yml
server:
  port: ${SERVER_PORT}
  servlet:
    context-path: ${CONTEXT_PATH}

logging:
  level:
    root: INFO
```

### `api-java-bavaria-munich/src/main/resources/application-local.yml`

**Create locally** (gitignored). Use fixed values for running with the `local` profile:

```yml
server:
  port: 8080
  servlet:
    context-path: /api

logging:
  level:
    root: INFO
```

### `api-java-bavaria-munich/.env.example`

Template for environment variables consumed by the **`cloud`** profile. Copy to **`.env.local`**.

```env
SERVER_PORT=8080
CONTEXT_PATH=/api
```

### `.gitignore` (monorepo root)

Ensure local secrets and the local profile are not committed:

```gitignore
# --- Secrets / local env ---
.env
.env.*
!.env.example

# Spring local profile (machine-specific, not committed)
**/application-local.yml
**/application-local.yaml
**/application-local.properties
```
