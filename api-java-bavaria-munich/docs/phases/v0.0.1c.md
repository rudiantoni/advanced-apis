# v0.0.1c (Sub-Phase 1c): API documentation (OpenAPI / Swagger UI)

Part of the **platform integrations phase** (read the **platform integrations phase index** first).

**Prerequisites:** complete the **platform configuration sub-phase** and the **container image sub-phase**.

Goals:

1. Add springdoc OpenAPI so the API is browsable and machine-readable while the codebase still has only scaffold endpoints.
2. Expose Swagger UI and the OpenAPI JSON document under the existing `context-path` (`/api`).
3. Register a minimal `OpenApiConfig` (title and version only).

## URLs

With the app running on port `8080` and `server.servlet.context-path: /api`:

| Resource | URL |
|----------|-----|
| Swagger UI | `http://localhost:8080/api/swagger-ui/index.html` |
| OpenAPI JSON | `http://localhost:8080/api/v3/api-docs` |

When running the API in Docker, use the port from your `.env.local` (for example `9001`).

## Docker note

Do this **after** the file changes in **Files** below if you run the API in Docker. Rebuild the image so the container includes the new springdoc dependency:

```bash
docker compose build
docker compose up -d
```

## Verify

Do this **after** the file changes in **Files** below.

1. Start the application (`bootRun`, the executable JAR, or Docker Compose from the **container image sub-phase**).
2. Open Swagger UI at the URL above.
3. Confirm `GET /open/check` and `GET /closed/check` appear and execute successfully.
4. Open `/api/v3/api-docs` and confirm `info.title` is `api-java-bavaria-munich`.

## Files

### `api-java-bavaria-munich/build.gradle`

Add the springdoc dependency (Spring Boot 2.7 uses the **1.x** springdoc line):

```gradle
dependencies {
    implementation 'org.springdoc:springdoc-openapi-ui:1.8.0'
    // ...
}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/OpenApiConfig.java`

New configuration class. Basic API metadata only.

```java
package com.myapps.bavariamunich.config;

import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.info.Info;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class OpenApiConfig {

    @Bean
    public OpenAPI openApi() {
        Info info = new Info()
                .title("api-java-bavaria-munich")
                .version("v1");

        return new OpenAPI()
                .info(info);
    }

}
```
