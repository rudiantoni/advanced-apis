# v0.0.1-idx (Phase 1 index): Platform integrations

Adds **platform integrations** wired into the API while the domain surface is still small.

## Prerequisites

Complete the **scaffold phase** (executable project with check endpoints and `context-path: /api`). Read this index before implementing any sub-phase below.

## Sub-phases for this phase

| Sub-Phase | Topic | Summary |
|-----------|-------|---------|
| 1a | **Externalized configuration** | Spring profiles `local` / `cloud`, `application-cloud.yml`, gitignored `application-local.yml`, `.env.example` → `.env.local`. |
| 1b | **Container image and local Compose** | Multi-stage Dockerfile, `docker-entrypoint.sh`, module `docker-compose.yml`, `.env.local` + `DATABASE_HOST` override, external network `dev_default`. |
| 1c | **API documentation** | OpenAPI 3 + Swagger UI via springdoc; minimal `OpenApiConfig`. |
| 1d | **New Relic APM** | Java agent (`-javaagent` + `NEW_RELIC_*`); Docker toggle via entrypoint and `NEW_RELIC_AGENT_ENABLED`. |

**Platform (runtime):** 1a → 1b. **Integrations (features):** 1c → 1d.

## How to proceed

1. Confirm prerequisites above.
2. Implement Sub-Phase **1a** (`v0.0.1a.md`) end to end.
3. Implement Sub-Phase **1b** (`v0.0.1b.md`).
4. Implement Sub-Phase **1c** (`v0.0.1c.md`).
5. Implement Sub-Phase **1d** (`v0.0.1d.md`).
6. Continue with the next guide in filename order (`v0.0.2.md`).
