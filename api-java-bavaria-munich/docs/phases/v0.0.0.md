# v0.0.0 (Phase 0): Executable project scaffold

Goals:

1. A runnable project using Java 8 and Spring Boot 2.7, with a working build and smoke test.
2. Public check endpoints for basic API validation (`GET /api/open/check`, `GET /api/closed/check`).
3. Base configuration holders in `config`: `AppConsts` for shared constants, `AppProperties` for runtime values set at startup, and `AppConfig` as the class where that initialization runs. Values in this phase are **scaffold placeholders** only; a later phase replaces each holder with real application code (see each holder's section below).

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/AppProperties.java`

Static properties holder. Setters only apply the first value so startup configuration cannot be overwritten accidentally at runtime. **`myProperty` is a scaffold placeholder** - it stands in for real runtime configuration loaded at startup and must be **removed and replaced** in any phase in the future.

```java
package com.myapps.bavariamunich.config;

public class AppProperties {
    private AppProperties() {
    }

    private static String myProperty;

    public static void setMyProperty(String givenMyProperty) {
        if (myProperty == null) {
            myProperty = givenMyProperty;
        }
    }

    public static String getMyProperty() {
        return myProperty;
    }
}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/AppConfig.java`

Spring `@Configuration` that runs code at startup. Injects `Environment` and delegates to `myInitialization()` - a **scaffold placeholder** showing **where** startup initialization will live. **`myInitialization()` must be removed and replaced** in the **shared-utilities phase**, which replaces this entire demonstration class with real startup wiring.

```java
package com.myapps.bavariamunich.config;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.env.Environment;

@Configuration
public class AppConfig {

    private static final Logger logger = LoggerFactory.getLogger(AppConfig.class);

    private final Environment env;

    public AppConfig(Environment env) {
        this.env = env;
        init();
    }

    private void init() {
        myInitialization();
    }

    private void myInitialization() {
        logger.info("myInitialization started");

        logger.info("myInitialization finished");
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/controller/OpenController.java`

Public controller to verify the API is reachable without authentication.

```java
package com.myapps.bavariamunich.controller;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.Collections;
import java.util.Map;

@RestController
@RequestMapping("/open")
public class OpenController {

    private static final Logger logger = LoggerFactory.getLogger(OpenController.class);

    @GetMapping("/check")
    public ResponseEntity<Map<String, String>> readAll() {
        String msg = "OPEN CHECK: You reached the open endpoint SUCCESSFULLY.";
        logger.info(msg);
        Map<String, String> result = Collections.singletonMap("message", msg);
        return new ResponseEntity<>(result, HttpStatus.OK);
    }
}
```

When calling `GET /api/open/check`, expect status `200 OK` with the following response body:

```json
{
  "message": "OPEN CHECK: You reached the open endpoint SUCCESSFULLY."
}
```
