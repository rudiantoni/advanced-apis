# v0.0.6 (Phase 6): Shared utilities

Add reusable JSON helpers and wire them at startup.

Goals:

1. Extend previously added `JsonUtil` with `ObjectMapper`-backed serialization helpers intended for **later** application code.
2. Expose `LIST_STRING` as an **example** of a reusable `TypeReference` constant shortcut.
3. Replace the initial `AppConfig` scaffold demonstration with constructor-based startup that wires the Spring `ObjectMapper` into `JsonUtil` via `initializeJsonUtil()`, providing the default Spring JSON serializer/deserializer to be used in non-dependency injected contexts.

**What this phase uses immediately:** only `JsonUtil.setObjectMapper` (via `AppConfig.initializeJsonUtil()`). The existing `applyIfDefined` helper from the **partial-update phase** remains the other live call site for `JsonUtil`. **`fromJsonStr`, `toJsonStr`, and `LIST_STRING` are added here as reusable API**.

## Files

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/util/JsonUtil.java`

Extends the utility. New helpers require `setObjectMapper` to be called first (done in `AppConfig` below).

`LIST_STRING`, `fromJsonStr`, and `toJsonStr` are **preparatory API** for future features. Add them now so later code can reuse one JSON helper without duplicating `ObjectMapper` setup.

`LIST_STRING` illustrates how to declare a `TypeReference` constant for repeated use with `fromJsonStr` - for example parsing a JSON array of strings in services or mappers. Other layers may define their own `TypeReference` constants for different types.

```java
package com.myapps.bavariamunich.util;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.openapitools.jackson.nullable.JsonNullable;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.List;
import java.util.function.Consumer;

public class JsonUtil {

    private static final Logger logger = LoggerFactory.getLogger(JsonUtil.class);

    private static ObjectMapper objectMapper;

    public static final TypeReference<List<String>> LIST_STRING = new TypeReference<List<String>>() {};

    // ...

    public static void setObjectMapper(ObjectMapper mapper) {
        if (objectMapper == null) {
            objectMapper = mapper;
        }
    }

    private static void ensureMapperConfigured() {
        if (objectMapper == null) {
            throw new IllegalStateException("JsonUtil not initialized - ObjectMapper was not set");
        }
    }

    public static <T> T fromJsonStr(String jsonStr, Class<T> c) {
        ensureMapperConfigured();
        T obj = null;
        try {
            obj = objectMapper.readValue(jsonStr, c);
        } catch (JsonProcessingException e) {
            logger.error("Error when converting to class {} from a JSON String.", c.getName(), e);
        }
        return obj;
    }

    public static <T> T fromJsonStr(String jsonStr, TypeReference<T> typeRef) {
        ensureMapperConfigured();
        try {
            return objectMapper.readValue(jsonStr, typeRef);
        } catch (JsonProcessingException e) {
            logger.error("Error when converting from JSON String to type {}", typeRef.getType(), e);
            return null;
        }
    }

    public static <T> String toJsonStr(T obj) {
        ensureMapperConfigured();
        try {
            return objectMapper.writeValueAsString(obj);
        } catch (JsonProcessingException e) {
            logger.error("Error when converting from class {} to a JSON String.", obj.getClass().getName(), e);
            return null;
        }
    }

}
```

### `api-java-bavaria-munich/src/main/java/com/myapps/bavariamunich/config/AppConfig.java`

Replaces the **scaffold-phase** `AppConfig` demonstration entirely: remove `myInitialization()` and the demo-only flow. Injects `Environment` and the Spring `ObjectMapper`; private `init()` calls only `initializeJsonUtil()`.

`AppConfig` does **not** call `JsonUtil` for its own configuration loading - that would couple the class that bootstraps the util to the util itself.

```java
package com.myapps.bavariamunich.config;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.myapps.bavariamunich.util.JsonUtil;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.env.Environment;

@Configuration
public class AppConfig {

    private static final Logger logger = LoggerFactory.getLogger(AppConfig.class);

    private final Environment env;
    private final ObjectMapper objectMapper;

    public AppConfig(Environment env, ObjectMapper objectMapper) {
        this.env = env;
        this.objectMapper = objectMapper;
        init();
    }

    private void init() {
        logger.info("AppConfig initialization started");
        initializeJsonUtil();
        logger.info("AppConfig initialization finished");
    }

    private void initializeJsonUtil() {
        JsonUtil.setObjectMapper(objectMapper);
    }

}
```
