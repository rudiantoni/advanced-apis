# v0.0.1d (Sub-Phase 1d): New Relic APM (Java agent)

Part of the **platform integrations phase** (read the **platform integrations phase index** first).

**Prerequisites:** complete the **platform configuration sub-phase**. The **container image sub-phase** is required only if you run the API in Docker.

This sub-phase wires the **New Relic Java agent** using **`-javaagent`** and **`NEW_RELIC_*` environment variables**. Activation and deactivation change runtime wiring (commands, env, and the container entrypoint when using Docker). Keep `newrelic.jar` and `newrelic.yml` in the module; do not delete them to turn the agent off.

Goals:

1. Obtain and version `newrelic.jar` and `newrelic.yml` in the module root.
2. Add `NEW_RELIC_*` placeholders to `.env.example` (and local `.env.local` as needed).
3. Activate or deactivate the agent from the IDE, Gradle command line, executable JAR, and Docker.

## Agent package

### Official download

Download the Java agent from New Relic:

- Zip (current): [https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip](https://download.newrelic.com/newrelic/java-agent/newrelic-agent/current/newrelic-java.zip)
- Install / overview docs: [Install the Java agent](https://docs.newrelic.com/docs/apm/agents/java-agent/installation/install-java-agent/)

The zip includes `newrelic.jar` and a default `newrelic.yml`. **Do not author `newrelic.yml` by hand** — use the file from the agent zip (and keep it under version control with the JAR).

### Java LTS compatibility (minimum agent versions)

From New Relic’s [compatibility and requirements for the Java agent](https://docs.newrelic.com/docs/apm/agents/java-agent/getting-started/compatibility-requirements-java-agent/), minimum agent versions for **Java LTS** releases from 8 onward:

| Java (LTS) | Minimum New Relic Java agent |
|------------|------------------------------|
| 8 | 3.10.0 |
| 11 | 4.7.0 |
| 17 | 7.4.0 |
| 21 | 8.7.0 |
| 25 | 8.25.0 |

This API targets **Java 8**. Prefer a current agent release that still supports Java 8. Confirm details on the New Relic docs page above if you change the JDK.

### Confirm the agent JAR version

From the module root (or any directory that contains the JAR):

```bash
java -jar newrelic.jar -v
```

### Version control

`newrelic.jar` and `newrelic.yml` **must be versioned** in the repository. The monorepo `.gitignore` allows the agent JAR (`!**/newrelic.jar`). If those files are missing locally, download the agent zip, place `newrelic.jar` and `newrelic.yml` in the module root (`api-java-bavaria-munich/`), and commit them.

### Environment variables

This guide implements the New Relic agent through runtime environment variables. Do not put secrets in `newrelic.yml`.

| Variable | Purpose |
|----------|---------|
| `NEW_RELIC_LICENSE_KEY` | License key **secret** (not the key ID shown in the UI) |
| `NEW_RELIC_APP_NAME` | Application name in the New Relic UI |
| `NEW_RELIC_AGENT_ENABLED` | For Docker: must be exactly `true` for the entrypoint to attach `-javaagent`. For local runs with `-javaagent` already on the command line, the agent also honors this flag. |

**License key:** copy the secret value from New Relic (Account settings → API keys → **License keys**). Using the key ID or an ingest/API key causes `Invalid license key` at startup.

## Run

Do this **after** the file changes in **Files** below (`newrelic.jar` / `newrelic.yml` present, `.env.example` updated, and — for Docker — Dockerfile and entrypoint extended). All commands assume the current directory is `api-java-bavaria-munich/`.

Smoke check after startup: `GET http://localhost:8080/api/open/check` (use `SERVER_PORT` when on `cloud` / Docker). Confirm the app name in New Relic → **APM** after generating traffic.

```bash
curl http://localhost:8080/api/open/check
```

### IntelliJ IDEA

For Gradle vs IntelliJ run settings and the harmless `BUILD FAILED` that can appear on Stop, see the module [README.md](../../README.md) (IntelliJ IDEA section).

1. Open this module so Gradle can sync.
2. Run → Edit Configurations… → use (or create) an **Application** (or **Spring Boot**) configuration.
3. **Main class:** `com.myapps.bavariamunich.ApiJavaBavariaMunichApplication`
4. **Working directory:** the module root (`…/api-java-bavaria-munich`)
5. Leave **Active profiles** empty.
6. **VM options** — choose one (agent on the same line as the profile). Load **`.env.local`** via EnvFile (include `NEW_RELIC_LICENSE_KEY` and `NEW_RELIC_AGENT_ENABLED=true`):
   - Local: `-Dspring.profiles.active=local -javaagent:newrelic.jar`
   - Cloud: `-Dspring.profiles.active=cloud -javaagent:newrelic.jar`
7. Apply / OK, then Run.

To deactivate: remove `-javaagent:newrelic.jar` from VM options and change `NEW_RELIC_AGENT_ENABLED` in **`.env.local`** to `false`.

### Docker Compose

Set `NEW_RELIC_AGENT_ENABLED=true` and a valid `NEW_RELIC_LICENSE_KEY` in **`.env.local`** to attach the agent. Set `NEW_RELIC_AGENT_ENABLED` to anything other than `true` (for example `false`) to run without the agent (same Compose commands; no CLI `-javaagent`).

#### Docker Compose - build (or rebuild) and start

```bash
docker compose --env-file .env.local up -d --build
```

#### Docker Compose - start (image already built)

```bash
docker compose --env-file .env.local up -d
```

#### Docker Compose - stop

```bash
docker compose --env-file .env.local down
```

### `api-java-bavaria-munich/docker-entrypoint.sh`

**Extends** the entrypoint from the **container image sub-phase**. Attach `-javaagent` only when `NEW_RELIC_AGENT_ENABLED` is exactly `true`.

```sh
#!/bin/sh
set -e

JAVA_OPTS=""

if [ "${NEW_RELIC_AGENT_ENABLED}" = "true" ]; then
  JAVA_OPTS="-javaagent:/app/newrelic.jar"
fi

exec java ${JAVA_OPTS} -Dspring.profiles.active=cloud -jar /app/app.jar
```

### `api-java-bavaria-munich/Dockerfile`

**Extends** the Dockerfile from the **container image sub-phase**. Copy the versioned agent files into the run stage (alongside the existing entrypoint copy).

```dockerfile
# ---- Build ----
FROM amazoncorretto:8-alpine3.21-jdk AS build

WORKDIR /app

COPY gradlew settings.gradle build.gradle ./
COPY gradle ./gradle
RUN chmod +x gradlew

COPY src ./src

RUN ./gradlew bootJar --no-daemon -x test \
    && cp build/libs/api-java-bavaria-munich-*.jar app.jar

# ---- Run ----
FROM amazoncorretto:8-alpine3.21-jre AS run

WORKDIR /app

RUN addgroup -g 10001 appgroup \
    && adduser -D -u 10001 -G appgroup appuser

COPY --from=build --chown=appuser:appgroup /app/app.jar /app/app.jar
COPY --chown=appuser:appgroup newrelic.jar /app/newrelic.jar
COPY --chown=appuser:appgroup newrelic.yml /app/newrelic.yml
COPY --chown=appuser:appgroup docker-entrypoint.sh /app/docker-entrypoint.sh

RUN chmod +x /app/docker-entrypoint.sh

USER appuser

ARG SERVER_PORT=8080
EXPOSE ${SERVER_PORT}

ENTRYPOINT ["/app/docker-entrypoint.sh"]
```
